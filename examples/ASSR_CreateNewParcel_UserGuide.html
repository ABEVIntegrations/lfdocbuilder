Create New Parcel

A quick reference for what this workflow does, what it needs from you, and what to expect when it runs.

When a new property parcel is added to the system, this workflow automatically builds the complete folder structure in Laserfiche — the main parcel folder, all required department subfolders, and the proper metadata — so the parcel is immediately ready to receive documents. When it's done, you'll receive a confirmation email with a direct link.

What You (or the Form) Provides

These six values are passed into the workflow when it starts. If you're triggering this from a form, the form collects them for you.

Parcel ID (SBL)
The Section-Block-Lot identifier for this property
e.g. 11.07.23
Street Number
The house / building number on the street
e.g. 100
Street Address (Name)
The street name, without the number
e.g. MAPLE AVE
Street Letter
The alphabetical grouping letter used for folder filing (A–Z)
e.g. M
Email Address
Where the confirmation email is sent when complete
e.g. user@town.gov
Linked Parcel Entry ID
Optional — links this parcel to a related existing record
Internal Laserfiche ID

What Happens, Step by Step

1
Check if the parcel already exists
The workflow first looks in the Inactive Parcels archive to make sure a parcel with this SBL doesn't already exist. This prevents accidental duplicates.
2
Create the main parcel folder
A new folder is created inside \Parcels\[Letter]\[Street Name]\ and named using the street number, street name, and SBL. The Properties template is applied with the parcel's metadata.
3
Build all department subfolders
Seven subfolders are created inside the parcel folder — one for each department that may file documents against this parcel: Assessor, Building, Engineering, Photos, Planning, Tax Bills, and Water.
4
Set folder permissions
Certain subfolders (Assessor, Engineering, Photos, Planning, and Water) are restricted so that the general Read Only group cannot access them. This protects sensitive department records.
5
Send a confirmation email
An email is sent confirming the parcel was created, including the Parcel ID, address, and a direct link to the new folder in Laserfiche.

The Folder Structure Created

Every new parcel gets this exact folder layout automatically.

\Parcels\[M]\MAPLE AVE\100 MAPLE AVE 11.07.23\ ├── Assessor⊘ Read Only access removed ├── Building ├── Engineering⊘ Read Only access removed ├── Photos⊘ Read Only access removed ├── Planning⊘ Read Only access removed ├── Tax Bills └── Water⊘ Read Only access removed

What to Expect

✅
Parcel created successfully
You'll receive an email with the subject "Parcel Created! [SBL]" containing the address and a direct link to the new folder. The parcel is immediately ready to use.
⚠️
Parcel already exists — not created
If a parcel with that SBL is found in the Inactive Parcels archive, the workflow stops and sends a notification: "Your parcel has NOT been created because it already exists." The existing record should be reviewed and reactivated instead of creating a new one.
